# Virginia EcoMechanical Website Redesign

## About the Project

This project is a redesign of the Virginia EcoMechanical HVAC-R Solutions website.

The goal is to create a modern, responsive, and user-friendly website that improves navigation, accessibility, and the presentation of the company's services.

This project also serves as an opportunity to strengthen my front-end web development skills.

## Features

Planned features include:

- Responsive design for desktop, tablet, and mobile devices
- Improved navigation menu
- Organized HVAC service information
- Contact form for customer inquiries
- Improved accessibility and user experience

## Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive layouts
- **JavaScript** — Interactive functionality
- **Git & GitHub** — Version control

## Getting Started

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
